# Meu Projeto do Filme - Scarface 

## 🚀 Como testar o projeto localmente

### 1. Clonar o repositório
```bash
git clone [https://github.com/lucasvn1/Tony-Montana](https://github.com/lucasvn1/Tony-Montana)
cd Tony-Montana
```
-------

### 2. Criar o Ambiente Virtual
### Windows
```bash
python -m venv venv
venv\Scripts\activate
```
### Linux/MacOS
```bash
python -m venv venv
source venv/bin/activate
```
-------

### 3. Instalar Dependências 
```bash
pip install -r requirements.txt
```
-------

### 4. Executar  
```bash
python app.py
```
